## The entry

A mum who kept every drawing her child ever made — even the bad ones — and then framed the worst one and hung it in the hallway, because that one is her favourite. A small family scene about love that does not grade on quality. The entry is a single scene in two sentences (159 characters), told plainly, with the twist landing in the mum's own words at the end.

The program uses only the Python standard library and takes no arguments.

## How to run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
